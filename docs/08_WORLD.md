# UNDO — World

## Setting

The game is set in a Korean public-record preservation facility tentatively named:

**중앙기록보존원 제4보존소**  
**Central Records Preservation Service — Repository 4**

Internal shorthand: **Repository 4** or **R4**.

The exact institutional naming may be revised during localization/legal review, but the setting remains a mundane public records institution rather than a secret supernatural organization.

## Public purpose

Repository 4 stores long-term materials including:
- administrative records,
- photographs,
- audiovisual media,
- facility logs,
- accident investigation records,
- CCTV originals,
- legally preserved records,
- damaged media awaiting restoration.

## Event Preservation research

Repository 4 historically hosted an experimental program for accident reconstruction.

The program unified independent sources into a **Causal Event Model** describing:

```
Before state
→ actor/action
→ after state
```

The original purpose was analytical: determine which actions caused which consequences during complicated failures.

## Record Correction

Researchers discovered that under specific conditions, invalidating a sufficiently corroborated recorded state-change could cause the present state to align with the revised record.

Institutional terms include:
- Correction,
- State Correction,
- Event Suppression,
- Record Invalidation.

The phenomenon never became a general-purpose technology because it is:
- narrow in scope,
- dangerous,
- difficult to reproduce,
- dependent on dense recording infrastructure,
- causally unpredictable when used repeatedly.

## Constraint

Only events strongly represented in Repository 4's recording systems are normally correctable.

This explains why mechanical/institutional state changes are available while thoughts, emotions, speech, and ordinary unrecorded behavior are not.

## Unknown mechanism

The story does not establish a definitive scientific explanation for why records can alter present state.

Historical researchers considered competing models, such as:
- recorded observation stabilizing state,
- reality/record consistency enforcement,
- selection among possible present states.

None is confirmed.

Do not introduce vague quantum jargon as an authoritative explanation.

## No global conspiracy

The correction phenomenon did not secretly rewrite world history. The narrative remains centered on one facility, one historical accident, and one person's unresolved question.

## Present-day trigger

Repository 4 is being partially closed/migrated. During final archival migration, older causal records and a dormant Correction subsystem become connected again.

An abnormal record designated **Record 0** enters the indexing path and destabilizes state consistency across the facility.

The system is not sentient and does not become an evil AI. The failure is an incompatibility between the correction model and a record representing an expected event that never occurred.
