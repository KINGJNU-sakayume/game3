# UNDO — Narrative

## Core dramatic arc

Han Jaemin, a long-serving records-integrity employee, is completing his final night shift during Repository 4's migration and closure process.

A dormant correction system begins producing real-world state inconsistencies. Jaemin initially tries to leave the building, then follows the failure downward through the archive layers.

The central corrupted object is **Record 0**, connected to an accident sixteen years earlier in which colleague Yoon Seojin died.

The game ultimately reveals that the key interval in Record 0 is a 39-second period during which Jaemin received a request for help but generated no qualifying state-changing response.

The player, after spending the entire game suppressing actions, reaches a gap containing no action to suppress.

## Narrative progression

Player objective evolves naturally:

```
Leave the building
→ restore local system stability
→ identify migration anomaly
→ investigate Record 0
→ reconstruct the historical accident
→ decide what happens to the present-day record
```

## Information policy

Plot must be understandable without optional lore collection.

Essential information is delivered through:
- mandatory spaces,
- environmental evidence,
- short system records,
- CCTV/communications,
- required interactions.

Optional materials deepen character and institutional context but do not contain indispensable plot facts.

## Reveal ladder

| Stage | Player learns |

| Start | Jaemin is working a final night shift during migration/closure |
| L03 | an old employee named Yoon Seojin existed |
| L05 | traces of Seojin's daily working life |
| L07 | part of B3 was closed after a historical accident |
| L08 | Seojin was a restoration technician |
| L09 | Jaemin and Seojin worked together |
| L10 | an abnormal file called Record 0 exists |
| L11 | both were on duty the night of the accident |
| L12 | Seojin was trapped during a compound facility failure |
| L13 | Jaemin had remote emergency-release authority |
| L14 | Seojin directly asked Jaemin to check the door/system |
| L15 early | Jaemin delayed a state-changing response for 39 seconds |
| L15 late | the gap itself is not an undoable event |
| L16 | the present-day institutional record can still be preserved, destroyed, or left contradictory |

## Narrative restraint

Do not use:
- long guilt monologues,
- a late reveal that the protagonist was secretly responsible for everything,
- "it was all an experiment",
- protagonist-is-dead twists,
- sentient evil facility AI,
- audio diary exposition chains,
- explicit FORGIVENESS / ACCEPTANCE / LET GO messaging.

The mechanics should carry the thematic conclusion.

## Final choice

There is no dialogue-choice or moral-choice menu.

The current system begins archival destruction of Record 0. That destruction is a recorded event and can therefore be suppressed or manipulated.

Possible final states include:
- the record remains institutionally preserved,
- the record is destroyed while Jaemin's memory remains,
- physical record persists while the institutional index says it does not exist.

The game does not label these Good, Bad, or True endings.

## Final image

Jaemin leaves the facility near dawn. The exterior door closes behind him.

After a game spent reading door closures as opportunities for correction, this final door shows no Residual Exposure and offers no Review interaction.

It simply closes.

Cut to black.
