# UNDO — Art Direction

## Visual identity

Core phrase:

> Aging Korean public-record facility + institutional realism + photographic double exposure.

The game is neither futuristic nor ruined.

The target is a facility that is:
- maintained,
- repeatedly renovated,
- visibly old,
- administratively mundane,
- increasingly uncanny through inconsistency rather than decay.

## Environment palette

Base environment:
- off-white,
- concrete gray,
- muted institutional green,
- beige,
- dark metal,
- aged wood/laminate,
- fluorescent white.

Correction phenomenon:
- one restrained, low-saturation amber family.

Exact color values remain to be established in visual prototypes.

Correction amber must not become the institution's general UI/signage color.

## Materials

Prioritize:
- painted concrete,
- linoleum/vinyl floors,
- steel doors,
- steel shelving,
- laminate desks,
- aged plastics,
- glass,
- aluminum frames,
- fluorescent fixtures,
- labels, tape residue, replacement patches.

Avoid making the building a post-apocalyptic ruin.

Use:
- faded paint,
- mismatched replacement tiles,
- old labels,
- repaired surfaces,
- varying fluorescent color temperature,
- temporary printed notices.

Avoid excessive:
- collapsed ceilings,
- heavy rust,
- vines,
- abandoned-hospital horror dressing.

## Era gradient

### Ground
Contemporary office renovation, some LED fixtures, current furniture.

### B1
2000s archive-office feel, fluorescent lighting, gray steel storage.

### B2
1990s industrial restoration infrastructure and control panels.

### B3
1980s heavy doors, analog instrumentation, legacy security.

### B4
Early facility construction, concrete, relay cabinets, exposed service systems.

### Record 0
Still the same building, but incompatible eras coexist in one space.

Do not transition into a white void, cyberspace, abstract neon world, or cosmic environment.

## Institutional uncanny

Tension comes from things that are almost ordinary:
- signage from the wrong era,
- a repaired door whose hardware predates the corridor,
- legacy telephone still connected,
- old personnel name appearing in a current list,
- inconsistent room labels,
- technology generations overlapping.

No monsters or jump-scare silhouettes.

## Lighting

Fluorescent lighting is a defining element.

Most lights work normally. Avoid horror-style constant flickering.

Use:
- subtle ballast hum,
- different color temperatures,
- delayed sensor activation,
- occasional aged tube behavior,
- practical service lighting.

Residual Exposure should not emit strong light. It is an overlapping state, not magical illumination.

## Graphic standards

The institution needs a coherent internal graphic system:
- signage standard,
- document standard,
- equipment labeling,
- safety marking,
- archive classification.

Modern areas, 2000s areas, and older areas should each have historically plausible variants.

Gameplay-critical text should be localization-ready rather than permanently baked into large textures wherever practical.

## Character appearance

Current staff should look like ordinary facility employees:
- shirts,
- work jackets,
- vests,
- ID cards,
- practical footwear,
- unremarkable office/work clothing.

Avoid exaggerated character silhouettes designed like hero-shooter characters.

Jaemin is first-person and should require minimal visible-body production. Hands/sleeves appear only where useful, such as document inspection.

## Key art

Preferred concept:
- one archive/facility door,
- current closed state and prior open state in photographic double exposure,
- restrained amber residual,
- small simple UNDO title.

Avoid character collages and generic sci-fi imagery.

## Explicit visual prohibitions

Do not default to:
- purple/blue gradients,
- glassmorphism,
- floating cards,
- pill buttons,
- neon borders,
- generic sci-fi HUD,
- glowing object outlines,
- excessive smooth app-style motion,
- holograms,
- AI/SaaS dashboard aesthetics,
- procedural-looking generated signage or unreadable fake text.

Final production signage/documents should be template/system-based, not raw generative image output.
